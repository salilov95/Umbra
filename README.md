# Umbra

Клиент для VLESS, Trojan, Shadowsocks и VMess под Windows. Внутри Xray-core, сверху интерфейс в отдельном окне. Написан на чистом Python без сторонних библиотек.

## Запуск

**Из исходников:** нужен Python 3.10+ (python.org, галка *Add python.exe to PATH*). Двойной клик по `run.bat`.

**Как .exe:** двойной клик по `build_exe.bat`. Скрипт сам создаст окружение, поставит PyInstaller и соберёт `dist\Umbra.exe`. Нужен интернет (pip) и пара минут. Если программа запущена, скрипт попросит сначала выйти из неё: Windows не даёт перезаписать работающий exe.

**Как установщик:** после `build_exe.bat` запусти `build_installer.bat`. Нужен Inno Setup 6 (jrsoftware.org). Получится `dist\Umbra-Setup-<версия>.exe`: ставит программу для текущего пользователя без прав администратора, создаёт ярлыки, при удалении возвращает прокси Windows.

## Перенос на другой компьютер

Скопируй папку `dist` целиком:

- `Umbra.exe` запускается без Python.
- `core\` (появляется, если на этом ПК ядро уже скачано) позволяет работать без доступа к GitHub. Без этой папки ядро скачается при первом подключении.
- Серверы и настройки хранятся в `%APPDATA%\Umbra` и на другой ПК сами не переедут: добавь подписку заново. Если рядом с exe создать пустую папку `data`, программа будет хранить всё в ней. Так удобно носить клиент на флешке вместе с серверами.

На другом ПК нужен Windows 10/11 с Edge или Chrome: окно программы открывается через них.

## Как пользоваться

1. Скопируй ссылку на сервер (`vless://`, `trojan://`, `ss://`, `vmess://`) или адрес подписки и нажми Ctrl+V в окне (или кнопку «Добавить»).
2. «Проверить» измерит время запроса через каждый сервер, «Самый быстрый» сам выберет лучший.
3. Щелчок выбирает сервер, двойной щелчок подключает. Либо кнопка «Подключить».
4. На схеме видно, куда идёт трафик: бирюзовая линия ведёт через сервер, янтарная напрямую. Под «Интернет» показан адрес, под которым тебя видят сайты.

Закрытие окна сворачивает программу в трей (значок возле часов): щелчок по значку открывает окно, правая кнопка даёт меню «Открыть окно / Подключить / Выйти». Это отключается в настройках, тогда закрытие окна выключает программу.

## Возможности

| | |
|---|---|
| Протоколы | VLESS (`reality`, `tls`, `none`), Trojan, Shadowsocks (AEAD и 2022), VMess; транспорты `tcp`, `ws`, `grpc`, `xhttp` (с `extra=`), `httpupgrade` |
| Подписки | plain и base64, название, остаток трафика и срок действия (если панель их отдаёт), автообновление при запуске |
| Маршруты | «Кроме российских сайтов» или «Весь трафик»; свои списки «всегда напрямую» и «всегда через сервер»; готовые наборы: блокировка рекламы, российские сервисы напрямую, торренты напрямую |
| Перенос на телефон | QR-код со ссылкой сервера (действие «QR» в строке сервера) |
| Уведомления | из трея: обрыв и восстановление связи, сервер не отвечает, смена сервера, подписка заканчивается через 5 дней или раньше, вышла новая версия |
| Проверка серверов | время запроса через туннель каждого сервера (отдельный временный Xray, рабочее соединение не трогается); «не работает» означает, что сервер на связи, но ключ или настройки не подходят |
| Контроль | скорость и объём в реальном времени, проверка туннеля каждые 20 секунд, выходной IP, тест скорости на приём |
| Проверка сайта | «Проверить сайт»: открывается ли сайт напрямую и через выбранный сервер, с кнопками «всегда через сервер» и «всегда напрямую» |
| Трей | работа в фоне, меню значка, автозапуск сразу в трей (в .exe) |
| Оформление | тёмная и светлая темы, пять акцентных цветов (Настройки → Оформление) |
| Надёжность | авто-восстановление при падении ядра, переключение на другой сервер, если текущий не отвечает (включается в настройках) |
| Запуск | автоподключение при старте, автозапуск с Windows (только в .exe) |
| Порты | SOCKS5 `127.0.0.1:10808`, HTTP `127.0.0.1:10809` |

Пока ядро не скачано, в списке показывается только TCP-отклик серверов (серым). После первого подключения «Проверить» измеряет запрос через туннель.

## Обновления программы

Программа умеет только проверять, вышла ли новая версия, и открывать страницу загрузки. Сама она ничего не скачивает и не заменяет.

Чтобы проверка заработала, впиши свой репозиторий в `umbra/__init__.py`: `UPDATE_REPO = "владелец/репозиторий"`. Новые версии публикуй как GitHub Releases с тегом вида `v0.5.1`. Пока строка пустая, программа за обновлениями не обращается.

## Безопасность

- **Прокси Windows.** Старые значения сохраняются до изменения и возвращаются при отключении, выходе и при следующем запуске после сбоя. Если интернет пропал после аварийного закрытия, запусти `restore_proxy.bat` или просто открой программу.
- **Ядро.** Архив с GitHub принимается только при совпадении SHA-256 с файлом `.dgst`.
- **Локальный интерфейс.** Сервер слушает только `127.0.0.1`; каждый запрос проверяется по случайному токену, заголовкам `Host` и `Origin`. Ключи серверов и адрес подписки в интерфейс не отдаются. Ссылка с ключом выдаётся только по кнопке «Ссылка».
- **Внешние обращения:** GitHub (ядро), адрес твоей подписки, через туннель `gstatic.com/generate_204` (проверка), `cloudflare.com/cdn-cgi/trace` (выходной IP) и тестовый файл для замера скорости (по кнопке; по очереди пробуются `speed.cloudflare.com`, `proof.ovh.net`, `fsn1-speed.hetzner.com`, `cachefly.cachefly.net`). Проверка сайта обращается к тому адресу, который ты ввёл.

## Проверено и не проверено

Проверено в Linux-песочнице на настоящем Xray 26.3.27 (59 тестов; QR-коды проверены декодированием через OpenCV для версий 1–20): разбор ссылок и подписок, конфиги для всех транспортов (`xray run -test`), сквозной трафик через локальные серверы VLESS, VMess, Trojan и Shadowsocks, замер задержки через туннель (включая нерабочий сервер и неверный ключ), тест скорости, маршрутизация, счётчики трафика, проверка туннеля, авто-восстановление, загрузка ядра с проверкой суммы, защита локального сервера. Интерфейс проверен скриншотами в Chromium.

На Windows пользователем проверено: запуск окна, импорт подписки, загрузка ядра, подключение, системный прокси, маршрутизация.

**Не проверено:** `build_installer.bat` и сценарий Inno Setup, трей (он написан напрямую на Win32 API и запускается только в Windows; в песочнице проверены лишь размеры структур), доступность хостов для теста скорости, автозапуск с Windows, папка `core` рядом с exe, кнопка «Открыть папку данных». Антивирус может ругаться на exe, собранные PyInstaller: это известное ложное срабатывание на загрузчик.

## Ограничения

- Только системный прокси, без TUN: программы, которые игнорируют прокси Windows, идут мимо. Им можно указать адрес SOCKS5 вручную.
- Не поддерживаются: Hysteria2, TUIC, WireGuard, Shadowsocks с плагинами, зашифрованные подписки `happ://crypt…`.

## Тесты

```
python -m unittest discover -s tests -t .
```

Сквозные тесты включаются переменной `XRAY_DIR` (папка с `xray`, `geoip.dat`, `geosite.dat`) и рассчитаны на Linux.
